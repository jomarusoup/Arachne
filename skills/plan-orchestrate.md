# Plan Orchestrate

복잡한 작업을 바로 구현하지 않고 실행 가능한 단계로 나누는 스킬이다.

## 언제 사용하나

- 3개 이상 파일을 바꾸는 기능
- 아키텍처 선택이 포함된 작업
- 테스트, 문서, 마이그레이션, UI가 함께 움직이는 작업
- Claude, Codex, Gemini 역할 분담이 필요한 작업

## 계획 형식

```markdown
## 목표
## 현재 상태
## 범위
## 제외 범위
## 단계
1. 조사
2. 설계
3. RED 테스트
4. 구현
5. 검증
6. 문서화
## 위험
## 완료 조건
```

## 역할 분담

| 역할 | 적합한 일 |
| --- | --- |
| Claude | 설계, 구현, 통합, 커밋 |
| Codex | 테스트 작성, 실패 재현, 버그 수정 |
| Gemini | 대량 읽기, 요약, 대안 조사 |

단독 사용 시에도 같은 역할을 사고 절차로 적용한다.
