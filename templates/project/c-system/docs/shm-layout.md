# 공유메모리 레이아웃

> 이 프로젝트가 쓰는 공유메모리 세그먼트의 정본 목록이다. 세그먼트를 추가·변경·삭제하면
> 같은 변경에서 이 표를 고친다. 장애 때 운영자가 가장 먼저 여는 문서이므로 빈칸 없이 채운다.
> 작성 기준은 `shm-db-patterns` 스킬, 레코드 설계는 `c-data-structures` 스킬을 따른다.

## 1. 세그먼트 목록

| 이름 | 방식 | 레코드 타입 | 레이아웃 버전 | 용량(건) | 크기(바이트) | 권한 | 소유(생성·적재·삭제) 프로세스 | attach 프로세스 |
|---|---|---|---|---|---|---|---|---|
| `/서비스_item` | POSIX | `ItemRec` | 1 | 100000 | 128 + 64 × 용량 | 0640 | `loader`(pidfile: `/var/run/서비스/loader.pid`) | `worker` × N, `shm_view` |
| | | | | | | | | |

- 이름은 `/서비스이름_용도` 형식, 30자 이하(macOS 한도). 운영·테스트 이름을 섞지 않는다.
- 크기 = 헤더 128바이트 + 레코드 크기 × 용량. 용량은 최대 건수 × 여유율(예: 1.3)로 잡는다.
- 소유 프로세스의 pidfile 경로를 적는다. `shmctl.sh remove --pidfile` 이 이 값을 쓴다.

## 3. 레코드 필드

레코드 헤더(`*.h`)의 `ITEM_FIELD_LIST` X-매크로가 정본이다. 이 표는 사람이 읽기 위한 사본이다.
필드를 바꾸면 레이아웃 버전을 올리고 이 표도 고친다.

| 필드 | 타입 | 오프셋 | 크기 | 의미·단위 | 개인정보 | 조회 도구 마스킹 |
|---|---|---|---|---|---|---|
| `item_id` | `uint32_t` | 0 | 4 | 품목 ID(주 키) | 아니오 | NONE |
| `group_id` | `uint32_t` | 4 | 4 | 그룹 ID | 아니오 | NONE |
| `prc` | `int64_t` | 8 | 8 | 가격(최소 호가 단위 정수) | 아니오 | NONE |
| `qty` | `int64_t` | 16 | 8 | 수량 | 아니오 | NONE |
| `last_ts` | `int64_t` | 24 | 8 | 마지막 갱신 시각(에포크 µs) | 아니오 | NONE |
| `name` | `char[16]` | 32 | 16 | 표시 이름(고객명 가정) | **예** | ALL |
| `flags` | `uint32_t` | 48 | 4 | 상태 비트(`ITEM_FLAG_*`) | 아니오 | NONE |
| `reserved` | `uint8_t[12]` | 52 | 12 | 명시 패딩 | - | (출력 안 함) |

- 개인정보 필드는 처리에 꼭 필요한 것만 둔다. 둘 때는 마스킹을 ALL 또는 DIGITS 로 지정한다.
