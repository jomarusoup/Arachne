# /learn — 패턴 학습

이 세션에서 발견한 비자명한 패턴을 rules에 저장.
다음 세션부터 자동 적용됨.

## 저장 위치 (패턴 성격으로 라우팅)

| 패턴 성격 | 위치 | 이유 |
| --- | --- | --- |
| 모든 CLI가 알아야 함 (구조·빌드·grep 키워드 등) | 프로젝트 `AGENTS.md` 해당 섹션 | Copilot 등 다른 CLI도 봐야 함 (프로젝트 SSOT) |
| 위 외의 비자명 패턴 | 프로젝트 `AGENTS.md` `## 학습된 패턴` | 〃 |
| Claude 전용 (훅·커맨드·에이전트 관련) | `.claude/rules/learned-YYYY-MM-DD.md` | 다른 CLI엔 무의미 |

저장 전 반드시 **반영할 diff를 보여주고 승인** 받는다 — 지침 파일은 매 세션
로드되므로 자동 누적 금지. 코드·git에서 파생 가능한 정보는 저장하지 않는다.

## 실행 타이밍
- 같은 실수를 두 번 이상 반복했을 때
- "이건 꼭 기억해야 한다"는 패턴 발견 시
- 특정 함수 수정 시 항상 같이 봐야 하는 파일이 있을 때

## 저장 형식
```markdown
# 학습된 패턴 — YYYY-MM-DD

## 패턴명
- 상황: ...
- 해결: ...
- 적용 범위: ...
```
