# /fix [버그 설명]

버그 수정 워크플로우. **파일 전체 읽기 금지.**

## 실행 순서

```
1. sgrep으로 위치 찾기
   sgrep "키워드|함수명"        # 전 확장자 검색
   sgrep "클래스|선택자"        # CSS/HTML 버그

2. 해당 범위만 Read로 확인
   (시작줄 ~ 끝줄만)

3. 재현 조건 명확히 정의
   - 어떤 입력·상태에서 발생하는가
   - 예상 동작 vs 실제 동작

4. 최소 범위 수정
   - 버그 원인에만 집중, 주변 코드 정리 금지

5. /verify 실행

6. 결과 보고
```

## 예시

```
/fix 소켓 연결 후 메모리 누수
/fix 함수 반환값 미확인으로 인한 segfault
/fix 캘린더 이벤트 렌더링 오류
/fix API 응답 파싱 실패
```
