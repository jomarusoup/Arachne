# ADR-0006: 2026 Q4 보강 로드맵 결정

## 상태

Accepted (2026-10-05)

## 배경

이 하네스로 개발할 대상은 3티어 시스템이다. 클라이언트는 웹과 TypeScript 데스크톱 앱, 서버는
Linux에서 도는 C 프로그램, DB는 Oracle과 PostgreSQL이다. 서버는 C++의 사상(캡슐화 등)을 C 문법으로
구현하는 방식을 쓰고, DB는 Pro*C·ecpg 임베디드 SQL로 다루며, 실시간 데이터는 공유메모리에 둔다.

2026-10-05 조사에서 하네스가 이 구조를 충분히 지원하지 못한다는 점이 확인됐다. 지식 수준의 규칙은
상당히 있지만, 공유메모리·복구·조회 도구, 네이밍 사전, 운영 로그, 대용량 처리 지침이 비어 있었다.
보안 규칙은 문서로만 있고 실행을 막는 장치가 하나도 없었다. 특히 Claude가 `.env` 같은 비밀 파일을
읽지 못하게 하는 설정이 없었다.

이 ADR은 로드맵을 실행하기 전에 정한 결정을 기록한다. 결정마다 선택지와 근거는
[로드맵](../task/20261005/2026-10-05-arachne-roadmap.md) §3에 있다.

## 결정

### 입력 시트로 확정한 결정

| 결정 | 내용 |
| --- | --- |
| D-06 서버 구조 | C 자체 epoll 이벤트 루프 + 불투명 핸들·함수 포인터 인터페이스. Rust는 C 모듈의 점진 이식 대상 |
| D-07 DB 접근 | Pro*C·ecpg 임베디드 SQL 유지. OCI·libpq 직접 사용은 임베디드 SQL로 안 되는 경우만 |
| D-08 스키마 관리 | 도구 없이 `.sql` 파일 유지 + 버전 명명 규약(`V001__설명.sql`) + 적용 기록 테이블 |
| D-09 개발·분석 환경 | 로컬 Docker + 원격 ssh. 프로파일링은 개발·스테이징만, 인터넷 없는 서버는 수집 스크립트로 결과만 회수 |
| D-24 진행 방식 | 웨이브 단위, 브랜치 → PR |

### 공용 하네스와 프로젝트의 경계

하네스에는 판단 기준, 패턴, 도구 골격, 검사 도구만 둔다. 약어 사전 본문, 공유메모리 레이아웃과
키, 테이블 매핑 같은 실제 값은 프로젝트가 소유한다. 새 `c-system` 프로젝트 프로필이 그 자리를
만들어 준다.

## 대안

- **C++·Rust 서비스 프레임워크 중심(초안)**: 서버가 C 주력이라는 입력과 맞지 않아 범위에서 뺐다.
- **OCI·libpq를 기본 DB 접근으로**: 기존 Pro*C·ecpg 자산과 개발 방식을 버려야 해서 기각했다.
- **Flyway 도입**: 지금은 수동 `.sql` 관리로 충분하다. 명명 규약을 Flyway와 호환되게 정해 나중에
  옮길 수 있게만 했다.
- **프로젝트 세부(사전·레이아웃)까지 하네스가 소유**: 공용성이 사라져 기각했다.

## 결과

- 실행은 웨이브 W0~W7로 진행하고, 웨이브마다 task 문서(`docs/task/2026-10-05-roadmap-w1.md` ~ `-w7.md`)가 있다.
- 가정으로 둔 전제(대용량 수치, C# 필요 조건, C++ 표준, 회사·개인 코드 구분)는 입력되면 로드맵
  §1.4를 갱신하고, 결정이 바뀌면 이 ADR을 supersede한다.
- 스킬은 약 15개, 리뷰어는 2개 늘어난다. 최종 정리(W6)에서 개수 표기와 역할 중복을 다시 점검한다.

## 후속 확인

- **D-02 확정 (2026-10-05)**: 처리량 PoC에서 Node(TypeScript) 수신기가 초당 1만·10만·100만 건을 목표 대비
  100%, 유실 0건, p99 242µs 이하로 처리했다. 포화 지점은 초당 1,000만~2,000만 건 사이였다. 그래서
  데스크톱 클라이언트는 TypeScript(Electron)로 확정하고 C# 트랙은 보류한다. 단, 측정은 한 대의 macOS
  localhost에서 이뤄졌으므로 실제 두 호스트 네트워크·Windows 하드웨어·Electron 내부 측정에서 재개 조건
  (로드맵 D-02)에 걸리면 C# 트랙을 다시 연다.
  근거: [처리량 PoC 결과](../issue/2026-10-05-throughput-poc-result.md)
