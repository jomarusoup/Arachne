### 2026-10-05

- task 생성: 로드맵 W0에서 웨이브 단위로 분해했다.
- 철학 P3(`rules/systems`)를 먼저 넣고, 그 위에 데이터 계층·대용량 처리를 일곱 갈래로 나눠 진행했다.
  새 스킬 9개(c-data-structures, shm-db-patterns, operational-logging, stream-pipeline-patterns,
  c-server-patterns, c-to-rust-migration, oracle-patterns, api-contracts, load-testing)와
  C 템플릿(공유메모리·정렬 테이블·로거·SPSC 링버퍼·프레임 코덱·스트림 계약·FFI 예제), 처리량 PoC를 추가했다.
- PoC 결과로 D-02(TypeScript 클라이언트)를 확정했다.
- C 템플릿은 이 Mac(clang)에서만 실행됐다. Linux 전용 경로(robust 뮤텍스 등)는 CI Ubuntu 단계에서 처음 검증한다.
- 발견: macOS TSan은 libc `memcpy` 안의 접근을 보지 못한다. SPSC 링버퍼는 TSan 빌드에서만 바이트 단위로 복사해 검증한다.
