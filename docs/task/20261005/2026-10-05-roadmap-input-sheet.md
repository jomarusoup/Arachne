# 로드맵 착수 전 입력 시트

> **이 문서 하나만 채우면 된다.** 채운 내용은 Claude가 로드맵 §3, 철학 계획 §3, ADR로 옮겨 적는다
> (§4 반영 위치 표 참고).
>
> **작성법**
> - 선택지는 `[ ]`를 `[x]`로 바꾼다. 빈칸 `____`에는 값을 적는다.
> - 모르거나 아직 정하지 않았으면 **`모름`**이라고 적는다. 그 항목은 권장안으로 진행하고, 로드맵에
>   "가정"으로 표시해 나중에 바꿀 수 있게 한다.
> - **실제 비밀번호·키·개인정보 값은 절대 적지 않는다.** 종류와 존재 여부만 적는다.
> - 다 채웠으면 Claude에게 "입력 시트 작성 완료"라고 알린다. 착수는 별도로 "시작"이라고 할 때만 한다.
