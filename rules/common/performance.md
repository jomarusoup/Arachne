# 성능 최적화

> 모델 선택 기준(Haiku/Sonnet/Opus)과 codegraph·sgrep 조사 라우팅 표는
> `skills/research-routing.md` 스킬로 분리했다 — 필요할 때만 로드한다.

## 컨텍스트 창 관리

컨텍스트 창의 마지막 20% 구간에서 피해야 할 작업:

- 대규모 리팩터링 (파일 다수 수정)
- 여러 파일에 걸친 기능 구현
- 복잡한 상호작용 디버깅

컨텍스트 민감도가 낮은 작업 (언제든 가능):
- 단일 파일 편집
- 독립적인 유틸리티 작성
- 문서 업데이트
- 간단한 버그 수정

## 토큰 절약

- 파일 전체 읽기 금지 — `sgrep`으로 위치 먼저, 필요 범위만 `Read`
- 병렬 에이전트 활용 — 독립 작업은 동시 실행

## 빌드 실패 대응

빌드 실패 시:

1. `debugger` 에이전트 활용
2. 에러 메시지 단계적 분석
3. 수정 후 즉시 검증
4. 동일 패턴 재발 방지
